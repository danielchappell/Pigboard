What's available today

Pigboard is in development. This public website explains the product and its method; it does not provide access to a hosted service.

What works in the repository

The private repository includes reusable worker roles and skills, a GitHub Projects runtime for local Codex work, a standalone Cursor command and an offline workflow preview.

It also contains Jira metadata diagnostics and initial private-host and owner-access foundations. Those components do not establish a complete, verified hosted Jira delivery service.

These tools require authorized access to the private repository. They are not public downloads or a self-service product offered through this site.

What we're building toward

The intended product is a team-owned development service: submit a feature, work through discovery and reviewed design, and receive small, reviewed changes with visible decisions and evidence.

Board integrations, supported execution providers, role packages and agent access enable that method. Provider availability and hosted end-to-end operation remain work to verify.

We have not established customer demand, measured time savings or a guarantee of autonomous correctness. The method and its results need to earn that confidence.

Public hosted access is not available yet

This website is informational. There is no public signup, trial or hosted workspace to open here today.
