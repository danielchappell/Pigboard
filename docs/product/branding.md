# The Pigboard crew

Owner-approved names, 14 November 2026. Pigboard is the product. Its planned build
pipeline is presented as a pig-themed construction crew, coordinated by Pig Boss.
The names are approved; the Pig Boss manager and its coordination are not shipped.

| Crew name | Role | Description |
| --- | --- | --- |
| Pig Boss | Manager | Coordinates the work. |
| Hardhat Ham | Implementer | Plans the work and implements the plan. |
| Inspector Pork | PR reviewer | Independently reviews the pull request. |
| Snout Scout | QA | Tests the experience and sniffs out problems. |

Use these exact names and capitalization in marketing and character introductions.
Pair each name with its plain-language role when introducing the crew.

These four roles are the approved build-pipeline lineup. Future system components
are outside this naming decision. The construction theme describes the crew within
Pigboard; Pigboard remains the product name.

The names do not change role responsibilities, technical identifiers, permissions
or release status. See the [product requirements](README.md) for release scope,
the [delivery contract](delivery.md) for worker responsibilities and the
[Pig Boss definition](../architecture/pig-boss-operations.md) for the manager.

The naming decision is also recorded in
[PGB-93](https://scubapig.atlassian.net/browse/PGB-93?focusedCommentId=10422).
