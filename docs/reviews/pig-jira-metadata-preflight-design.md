Both reviewers independently assessed all seven principles. **Intuitive:** one fixed-PIG command and local route labels explain the check. **Discoverable:** help, text/JSON reasons and an operator guide describe use and recovery. **Delightful:** one run replaces repeated manual probes, with one-time protected-file setup. **Token saver:** selected facts and explicit omissions replace raw Jira dumps. **Secure:** protected credentials, fixed hosts, identity-first requests, redirect refusal and no issue/write reads constrain exposure. **Agents are equal:** JSON and exit codes carry the same evidence as human text without prompts. **Dependable:** failed, partial and empty-association results remain distinct, and exit zero claims only targeted metadata.
