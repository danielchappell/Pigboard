## Author assessment of the seven principles

1. **Intuitive:** the command displays PIG and returned board names with native IDs and types. It says selection and eligibility are later, so a listed board is not presented as runnable.
2. **Discoverable:** README, command help and first-service guide show setup, exact private route, text/JSON examples, omissions and recovery. Agents can discover the versioned response and exit behavior without prompts.
3. **Delightful experience:** current owner and agent reuse their own credential and peer and receive a complete small list in one call. A cold/slow provider can still require a bounded retry; the host closes the response itself at the absolute deadline for direct agents, and an interrupted image-check denial probe now returns a bounded failure instead of hanging the operator.
4. **Token saver:** the result leads with only useful names/IDs/types and explicit omissions. Image-check JSON/text now states that live Jira access remains unproved despite local import/denial checks. It never returns Jira raw bodies or forces agents to parse human text.
5. **Secure:** pre-OAuth and final same-principal live grants, exact PIG image manifest, account/cloud checks, managed host-only secrets and no partial names enforce the approved disclosure boundary. The route rechecks the absolute clock after each awaited stage and before sending names, even if a timer callback is delayed. Early provider failures cancel unread bodies and abort their transport. The interrupted image-check denial probe reaches exact owned cleanup; a provider-visible board's actual filter remains unverified.
6. **Agents are equal:** owner and fixed agent call the same route with their own current bearer/private peer; both receive equal choices, and JSON plus noninteractive exit codes support the agent directly. Neither receives secret or scope administration.
7. **Dependable:** complete, denied, unavailable, uncertain and local unverified remain distinct; incomplete pages, board access refusal and revoked grants disclose no names. Board and OAuth 401/403 retain `jira_unavailable` for documented 503 recovery; OAuth redirects, malformed or oversized raw and parsed replies, and timeouts remain `metadata_unverified` for 502 recovery. The absolute route deadline aborts provider and owned database work, closes the HTTP response even on a delayed timer and handles late driver settlement; failed provider reads release their bodies without waiting unboundedly. The image-check denial probe settles on interruption or deadline so its owned cleanup executes. A revoke after the final check cannot retract bytes already sent, which the reviewed design states.
