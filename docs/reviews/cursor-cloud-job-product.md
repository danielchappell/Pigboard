## Seven-principle assessment

| Principle | Independent assessment for plan and code |
| --- | --- |
| Intuitive | `prepare`, `start` and `get` match the user's sequence. `FINISHED` means the provider turn ended, while the guide explicitly leaves answer validation to the caller. Humans see this distinction in prose; agents see status and terminal fields. |
| Discoverable | README points to the guide; CLI help, `models`, examples and JSON error codes expose the supported path. The generic `invalid_response` message could name a temporarily absent final reply more precisely, but it retains the IDs and the guide explains same-ID retry. |
| Delightful experience | A saved request and read-only recovery let a caller resume a lost launch without repeating a billable prompt. Both human operators and automation can continue from the retained IDs. |
| Token saver | Exact run retrieval takes one read; agent-ID fallback is bounded to a two-item list, and ambiguity is explicit. Agents can consume concise JSON without parsing a transcript. |
| Secure | The API key enters through environment or constructor, not the request file or CLI argument. The fixed API origin, rejected redirects, constrained request fields and redacted outputs limit credential exposure. The guide warns humans that plan mode and disabled automatic PR creation do not remove repository-write authority. |
| Agents are equal | Exported library methods and noninteractive JSON CLI support machine callers with explicit inputs and structured errors. The guide gives humans a normal-use and recovery path; neither path requires the Cursor chat UI. |
| Dependable | A lost create response remains uncertain until read-only reconciliation; multiple runs require exact identity; malformed or empty finished replies cannot be reported as success. The plan and guide separate queued, finished, failed, accepted and unverified-live states. |

The reviewed files do not provide hosted persistence or ticket authority. Those are named later slices and are not gaps in S03. CLEAN is a review verdict, not merge authorization or live acceptance.
